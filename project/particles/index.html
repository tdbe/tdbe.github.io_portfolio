GPGPU N-Body Particles
Personal Project
Autumn 2016

| I was researching making physics simulations and tools for VR. This one is a fun motion vfx physics experiment with "singularity" fields as brushes moving particles through various space mediums.







|It started as a short research project (2013) using Compute Shaders to manipulate voxel grids. It was integrated as a modelling and visualizing tool in my PCG Caves Thesis (sans motion).


There are 643 entities with color and velocities. I also generate 6^2 triangle (cube, or quad) in a geometry pass for each particle (3.145.728 tris).
[EDIT] Now using CommandBuffer.DrawProcedural() instead.
